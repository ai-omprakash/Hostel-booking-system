# 🏨 Hostel Booking System

A modern web-based Hostel Booking System developed using PHP and MySQL that helps students find and book hostel rooms easily while allowing administrators to manage hostels, rooms, users, and bookings efficiently.

---

# 📌 About the Project

The Hostel Booking System is designed to simplify hostel management and online room booking processes. Users can browse available hostels, view room details, upload required documents, and make bookings online. Administrators can manage users, hostel listings, room availability, bookings, and uploaded hostel images through a secure admin panel.

This project is useful for:
- Colleges and universities
- Student accommodation services
- Hostel management businesses
- PHP & MySQL learning projects

---

# ✨ Features

## 👨‍🎓 User Panel
- User registration and login
- Browse available hostels
- View hostel details and room information
- Upload documents/images
- Book hostel rooms online
- Manage personal profile
- Booking history

## 👨‍💼 Admin Panel
- Secure admin login
- Add/edit/delete hostels
- Manage hostel images
- Manage room availability
- View all users
- Manage bookings
- Upload hostel photos
- Dashboard management

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/ai-omprakash/Hostel-booking-system.git
```

---

## 2️⃣ Move Project Folder

Move the project folder into:

```bash
C:/xampp/htdocs/
```

---

## 3️⃣ Start XAMPP

Open XAMPP Control Panel and start:

* Apache
* MySQL

---

## 4️⃣ Create Database

1. Open phpMyAdmin
2. Create a database named:

```bash
hostel_booking
```

3. Import the SQL file from the `database/` folder.

---

## 5️⃣ Run the Project

Open your browser and visit:

```bash
http://localhost/Hostel-booking-system
```
